# 🌱 동건루틴

**내 자산과 일상을 기록하고, 글까지 남기는** 나만의 앱. 할 일 · 루틴 · 목표부터 식단 · 운동 · 독서 · 일기, 포트폴리오까지 한곳에. 서버 없이 브라우저(localStorage)에만 데이터를 저장하는 완전 프라이빗 개인 앱입니다.

## 주요 기능

- **오늘** — 날짜·시간별 할 일, 주간 스트립 탐색(**날짜를 길게 누르면 그 날에 바로 할 일 추가**), **손가락을 따라오는 좌우 스와이프로 날짜 이동**(미리보기 라벨·스냅), 루틴 체크, 밀린 할 일 관리, **💰 자산 한 줄 요약**(총자산·손익률·이번 달 예상 배당 — 탭하면 자산 탭으로), **✍️ 오늘의 글**, 하루 한 줄 회고(기분 이모지), **매일 바뀌는 오늘의 명언**(탭하면 복사), **출석 스트릭 배지**, 하루 100% 달성 시 **컨페티 축하**
- **기록** — 체중·칼로리·물(숫자, 누적 더하기 지원) / 독서·운동·식단(텍스트)처럼 매일의 변화를 자유롭게 기록, 목표값·목표 연결, 30일 추이 그래프
- **식단 · 운동 · 독서** — 매일의 생활을 구조적으로 기록: **식단**(아침/점심/저녁/간식), **운동**(종목·양·소모 칼로리, 합계 자동 표시), **독서**(책 제목·분량). 오늘 탭과 달력 날짜별 상세에서 기록·확인
- **메모장 · 글** — 떠오르는 생각·아이디어를 자유롭게 기록. 첫 줄이 제목, 📌 고정(상단 유지), 수정 시각 표시, 통합 검색(할 일과 함께 메모도 검색). **메모에 날짜를 달면 '그 날의 글'이 돼서** 달력·오늘 탭의 그 날짜에 함께 보여요 (전체 / 🗓️ 날짜 글 / 자유 메모 필터)
- **달력** — **구글 캘린더처럼 칸 안에 일정 제목이 그대로 보이는 월간 달력**. 오늘은 초록 원, 넘치면 `+N`, 매일 반복되는 루틴은 칸 아래 **달성 게이지**로, 그날 남긴 것은 **색 점**(글·식단·운동·독서)으로 표시. **월/목록 두 가지 보기**(목록 = 뭔가 있었던 날만 날짜순으로), 맨 위 **이 달 요약**(달성률·기록한 날·남긴 글·운동 일수·이번 달 예상 배당 — 탭하면 자산 배당 캘린더로), 날짜를 누르면 아래에 그 날의 일정·글·식단/운동/독서·회고 상세, **칸을 길게 누르면 그 날짜에 바로 할 일 추가**
- **루틴** — 요일별 반복, 연속 달성 스트릭 🔥, 보관 기능
- **목표** — 월간 / 분기별 / 연간 목표, D-Day, **측정값 진행률 자동 계산**(체중감량↓, 독서 권수·달리기 km·헬스 시간↑ 등 — 카드에서 바로 값 갱신·누적) · 마일스톤 체크리스트 · 직접 조절, 할 일 연결 · **💰 돈 목표(자산·연 배당·투자 수익)는 내 포트폴리오와 자동 연동**돼 현재값이 실시간 반영
- **자산 › 현재** — 내 포트폴리오 첫 화면 요약(분석랩 제외): 총 자산·평가손익·투자원금·연 배당(세후), **섹터별 포트폴리오 비중**, **보유 종목 리스트**(평가금액·비중·손익률·손익액 한눈에, **탭하면 현재가·평단·원금·연 배당·지급월 상세**, 비중/수익률/배당순 정렬), **배당 대시보드**(세전/세후 연 배당·월평균·하루평균, **월별 예상 배당 캘린더 — 월을 탭하면 그 달에 어떤 종목이 얼마 주는지 종목별 상세**, **배당 기여 TOP 종목**, 연 배당 목표 진행바), ₩/$ 전환, 자산 목표 진행바. 수치는 코드의 `PF_SNAPSHOT`으로 갱신
- **자산 › 기록** — 2021년부터 남겨온 과거 데이터: **자산 추이 그래프**(2021.03~2024.11 월별 총자산·투자원금, 이후 캡처 시점과 현재까지), 시점별 총자산·원금·누적수익 표, **실제로 받은 배당**(2021~2024 연도별·월별 실지급액, 그 해 배당 TOP 5, 지금 예상 배당과 비교), **포트폴리오 변천사**(2021.12 / 2022.03 / 2025.08 / 지금 — 시점별 종목 구성과 "정리한 종목 · 새로 담은 종목" 비교). 데이터는 코드의 `PF_HISTORY`에 있고, 출처는 `주식/미주 월별 수익.xlsx`, `주식/배당금.xlsx`, 토스증권 캡처
- **할 일 상세** — 서브태스크 체크리스트, 우선순위, 태그, 메모, 검색, 내일로 미루기, **날짜 옮기기**(오늘/내일/모레/다음 주 버튼 또는 직접 고르기), 복제
- **통계** — GitHub 스타일 잔디 히트맵, 주간 완료율 추이, 루틴별 달성률·스트릭
- **주간 리포트** — 매주 첫 방문 때 지난주 요약(완료율·전주 대비·최고의 날·루틴 성과·기록 변화)이 자동으로 떠요. 통계 탭에서 언제든 다시 보기
- **공유 카드** — 성취율·스트릭·활동 기록을 이미지 카드로 생성해 저장/공유 (데이터는 나가지 않고 카드만!)
- **PWA** — 폰 홈 화면에 설치, 오프라인 동작, 다크모드

## 사용 방법

👉 **https://kingofthestock.github.io/donggun-routine/**

### 폰에 설치하기

- **갤럭시(Android)** — Chrome으로 접속 → 메뉴(⋮) → **홈 화면에 추가** (또는 앱 설치)
- **아이폰(iOS)** — Safari로 접속 → 공유 버튼(□↑) → **홈 화면에 추가**

### 폰 ↔ PC 데이터 옮기기

데이터는 각 기기에만 저장됩니다. 기기 간 이동은:

1. 설정 → **백업 내보내기** (JSON 파일 저장)
2. 파일을 카톡 '나에게 보내기' 등으로 다른 기기에 전달
3. 다른 기기에서 설정 → **백업 가져오기**

> ⚠️ 브라우저 데이터를 지우면 기록도 사라져요. 주기적으로 백업해주세요!

## 프라이버시

- 모든 데이터는 **내 기기 안에만** 저장됩니다 (서버·계정·추적 없음)
- 공유 기능은 통계 이미지 카드만 생성합니다 — 원본 데이터는 어디에도 전송되지 않아요

## 기술

순수 HTML/CSS/JS 단일 파일 + Service Worker(오프라인) + Web App Manifest(설치형 PWA). 외부 라이브러리 0개.

로컬 실행: 폴더에서 `python -m http.server` 후 `http://localhost:8000` 접속.
